# Student service galleries

Each service unit has its own gallery. Add JPG, JPEG, PNG, or WebP photos to the
matching folder below. Photos appear in filename order; prefixes such as
`01-orientation.jpg` and `02-student-activity.jpg` let you choose the order.
The gallery uses the existing campus images until the unit has its own photos.
